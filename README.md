## 👋 About

Mobile & fullstack developer building software **since 2018** — specialized in **React Native**, with native **Swift**, **Kotlin** and **Java** modules and a **Node.js** back end. I design **offline-first** architectures that keep working without a connection and sync safely, and I've shipped **60+ projects** to the **App Store** and **Google Play**.

I've worked across fintech, logistics, real estate and automotive — from POS/card-machine apps to native truck systems — and led teams as a tech lead (architecture, code quality, mentoring, Scrum).

- 🧩 **Focus:** React Native · offline-first · native modules · clean architecture (Hexagonal / MVVM)
- 🛠️ **Back end:** Node.js · PostgreSQL · Docker · Firebase · CI/CD
- 🌐 **Languages:** Portuguese (native) · English (B2) · Spanish (C1)
- 💼 **Open to** full-time roles and freelance projects
